怎么装

  1. 点上面的按钮下载（37 MB，别用流量的话连个 WiFi）
  2. 下载完点通知栏里的安装包，或去「文件管理 → Download」找 Folia-Android-0.7.22.apk
  3. 系统提示「禁止安装未知应用」→ 点设置，把浏览器/文件管理的开关打开
  4. vivo / iQOO 会弹安全检测，选「继续安装」（这是自签名的非商店应用，属于正常提示）
  5. 装完打开，第一次会让你选音源；国内音源不用梯子，Spotify 和 YouTube Music 才需要

这个包是什么

Folia 官方只出了 Windows / macOS / Linux 桌面版， 没有官方安卓版。这个是社区移植版 whycfawa/folia-android （基于上游 AGPL-3.0 源码，用 Capacitor 套壳，加了后台播放和锁屏控制）。 签名是开发者的 debug 证书，所以以后如果换签名，需要先卸载再装。
